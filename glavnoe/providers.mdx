# Для провайдеров

Provider — фактический backend, исполняющий запрос к модели. Для подключения важны auth, RPM/TPM, pricing, context limits, streaming, tool calling, media capabilities и формат ошибок.

Клиентские приложения не должны зависеть от нестандартных полей одного provider: такие различия лучше изолировать в адаптере.
