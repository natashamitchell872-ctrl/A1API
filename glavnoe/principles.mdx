# Наши принципы

## Один контракт

Приложение работает с единым API, а различия конкретных провайдеров скрываются за routing-слоем.

## Совместимость

Базовые text endpoints повторяют привычный OpenAI-совместимый формат, поэтому существующие клиенты переносятся с минимальными изменениями.

## Прозрачность

В production сохраняйте модель, фактического provider, latency, usage и стоимость.

## Надёжность

Используйте fallback и повторяйте только временные ошибки. Не отправляйте сервисные API Keys в браузер или мобильное приложение.
