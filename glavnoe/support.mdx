# Поддержка

При ошибке подготовьте endpoint, HTTP status, model ID, provider, request id, время запроса и минимальный JSON body без секретов.

## Порядок диагностики

1. API Key и баланс.
2. Существование модели.
3. Поддержка параметров.
4. Формат входных файлов.
5. Provider routing.
6. Retry для 429/5xx.
