# GET Media Status

**GET `/v1/media/{id}`**

Статус асинхронной генерации.

## Авторизация

```http
Authorization: Bearer <A1_API_KEY>
```

## Параметры

Path: `id` — идентификатор генерации, полученный от `POST /v1/media`.

Ответ содержит поле `status` (`queued`, `processing`, `completed`, `failed`), результат в `output`/`result` и причину отказа в `error` при неуспешном завершении.

## Пример

```bash
curl -X GET "https://apia1.com/api/v1/media/{id}" -H "Authorization: Bearer <A1_API_KEY>"
```

## Ошибки

`400` — неверный запрос; `401` — auth; `403` — права; `404` — объект не найден; `429` — лимит; `5xx` — временная ошибка сервиса/provider.
