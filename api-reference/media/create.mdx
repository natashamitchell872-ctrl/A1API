# POST Media

**POST `/v1/media`**

Универсальная генерация медиа.

## Авторизация

```http
Authorization: Bearer <A1_API_KEY>
```

## Параметры

`model` и объект `input`; внутри обычно используются `prompt` и входные media URL/file refs.

## Пример

```bash
curl -X POST "https://apia1.com/api/v1/media" -H "Authorization: Bearer <A1_API_KEY>" -H "Content-Type: application/json" -d '{"model":"<MODEL_ID>","input":{"prompt":"Минималистичный постер"}}'
```

## Ошибки

`400` — неверный запрос; `401` — auth; `403` — права; `404` — объект не найден; `429` — лимит; `5xx` — временная ошибка сервиса/provider.
