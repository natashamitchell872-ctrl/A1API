# POST Media Operations

**POST `/v1/media/{id}/operations`**

Операции над существующими медиа.

## Авторизация

```http
Authorization: Bearer <A1_API_KEY>
```

## Параметры

Path: `id` — идентификатор существующего медиа.

Body: `operation` — название операции над медиа и её параметры. Набор поддерживаемых операций зависит от модели: проверяйте capability модели перед вызовом.

## Пример

```bash
curl -X POST "https://apia1.com/api/v1/media/{id}/operations" -H "Authorization: Bearer <A1_API_KEY>"
```

## Ошибки

`400` — неверный запрос; `401` — auth; `403` — права; `404` — объект не найден; `429` — лимит; `5xx` — временная ошибка сервиса/provider.
