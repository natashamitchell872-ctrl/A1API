# POST Embeddings

**POST `/v1/embeddings`**

Создание векторных представлений текста.

## Авторизация

```http
Authorization: Bearer <A1_API_KEY>
```

## Параметры

`model`, `input`, `encoding_format`, `dimensions`, `user`.

## Пример

```bash
curl -X POST "https://apia1.com/api/v1/embeddings" -H "Authorization: Bearer <A1_API_KEY>" -H "Content-Type: application/json" -d '{"model":"text-embedding-3-small","input":["первый текст","второй текст"]}'
```

## Ошибки

`400` — неверный запрос; `401` — auth; `403` — права; `404` — объект не найден; `429` — лимит; `5xx` — временная ошибка сервиса/provider.
