# Статистика хранилища

**GET `/v1/storage/stats`**

Статистика использования хранилища.

## Авторизация

```http
Authorization: Bearer <A1_API_KEY>
```

## Параметры

Может требовать административную/JWT-авторизацию в зависимости от политики аккаунта.

## Пример

```bash
curl "https://apia1.com/api/v1/storage/stats" -H "Authorization: Bearer <AUTHORIZED_TOKEN>"
```

## Ошибки

`400` — неверный запрос; `401` — auth; `403` — права; `404` — объект не найден; `429` — лимит; `5xx` — временная ошибка сервиса/provider.
