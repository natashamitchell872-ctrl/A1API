# Удалить файл

**DELETE `/v1/storage/files/{id}`**

Удаление файла из хранилища.

## Авторизация

```http
Authorization: Bearer <A1_API_KEY>
```

## Параметры

Path: `id` — идентификатор файла, который нужно удалить. Удаление необратимо: восстановить файл нельзя.

## Пример

```bash
curl -X DELETE "https://apia1.com/api/v1/storage/files/{id}" -H "Authorization: Bearer <A1_API_KEY>"
```

## Ошибки

`400` — неверный запрос; `401` — auth; `403` — права; `404` — объект не найден; `429` — лимит; `5xx` — временная ошибка сервиса/provider.
