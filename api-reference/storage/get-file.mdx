# Информация о файле

**GET `/v1/storage/files/{id}`**

Данные конкретного файла.

## Авторизация

```http
Authorization: Bearer <A1_API_KEY>
```

## Параметры

Path: `id` — идентификатор файла в хранилище.

Ответ содержит метаданные файла: имя, тип, размер, политику хранения и срок удаления.

## Пример

```bash
curl -X GET "https://apia1.com/api/v1/storage/files/{id}" -H "Authorization: Bearer <A1_API_KEY>"
```

## Ошибки

`400` — неверный запрос; `401` — auth; `403` — права; `404` — объект не найден; `429` — лимит; `5xx` — временная ошибка сервиса/provider.
