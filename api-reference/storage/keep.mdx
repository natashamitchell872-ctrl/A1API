# Сохранить файл навсегда

**PATCH `/v1/storage/files/{id}/keep`**

Перевод файла в постоянное хранение.

## Авторизация

```http
Authorization: Bearer <A1_API_KEY>
```

## Параметры

Path: `id` — идентификатор файла, переводимого в постоянное хранение. После вызова файл перестаёт удаляться по TTL.

## Пример

```bash
curl -X PATCH "https://apia1.com/api/v1/storage/files/{id}/keep" -H "Authorization: Bearer <A1_API_KEY>"
```

## Ошибки

`400` — неверный запрос; `401` — auth; `403` — права; `404` — объект не найден; `429` — лимит; `5xx` — временная ошибка сервиса/provider.
