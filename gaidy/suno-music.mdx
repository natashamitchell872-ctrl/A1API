# Suno Music Generate

Генерация музыки.

```bash
curl -X POST "https://apia1.com/api/v1/media" -H "Authorization: Bearer <A1_API_KEY>" -H "Content-Type: application/json" -d '{"model":"<MODEL_ID>","input":{"prompt":"Энергичный электронный трек без вокала"}}'
```

Длительность, lyrics, vocals и output format задавайте только если выбранная модель их поддерживает.
