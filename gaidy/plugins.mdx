# Плагины

Плагин добавляет внешнюю обработку вокруг вызова модели. Типичные задачи: web search, разбор документов и enrichment из внутренних сервисов.

```json
{"model":"openai/gpt-4o","messages":[{"role":"user","content":"Что нового сегодня?"}],"plugins":[{"id":"web"}]}
```

Плагины могут увеличивать задержку и стоимость — учитывайте их отдельно в наблюдаемости.
