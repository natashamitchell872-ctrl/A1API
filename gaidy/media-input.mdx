# Передача медиа на вход

Мультимодальные модели могут принимать typed content parts.

```json
{"role":"user","content":[{"type":"text","text":"Что на фото?"},{"type":"image_url","image_url":{"url":"https://example.com/photo.jpg"}}]}
```

Для крупных файлов удобнее сначала использовать Storage API. Поддержка аудио, видео и документов зависит от конкретной модели.
