# Topaz Upscale

Апскейл и улучшение изображений.

```bash
curl -X POST "https://apia1.com/api/v1/media" -H "Authorization: Bearer <A1_API_KEY>" -H "Content-Type: application/json" -d '{"model":"<MODEL_ID>","input":{"image_url":"https://example.com/input.jpg","scale":2}}'
```

Поддерживаемые коэффициенты увеличения и output format проверяйте в metadata модели.
